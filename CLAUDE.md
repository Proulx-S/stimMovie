# stimMovie

Pre-rendered visual fMRI stimulation movies (eccentricity-scaled flickering noise, a red fixation-dot
task) for playback in ePrime3. Entry point: `doIt.m`. All functions are self-contained in the repo.

- **Working branch:** `main` (an older project; it keeps its branch, bass rule `git-and-worktrees.md`).
- **Public repo:** no subject, collaborator or dataset names.
- **Notes:** [overview](docs/agent-notes/stimMovie-overview.md),
  [eccentricity-scaled noise](docs/agent-notes/eccentricity-scaled-noise.md),
  [LCH colorspace](docs/agent-notes/lch-colorspace-for-stimuli.md).
